# Outlined SVG masters

All lockup lettering has been converted to filled paths. The square
`primary-icon.svg` is the approved original; the symbol-only and one-colour
versions are secondary applications of the approved foreground geometry.
`primary-icon-dev.svg` is a separate non-production variant with a small red
`#C63D3D` DEV ribbon and cream path-outlined lettering. Do not substitute it for
the clean production icon.

- `logo-horizontal-color.svg` — primary full-colour horizontal lockup.
- `logo-horizontal-reverse.svg` — full-colour lockup on navy, with a gold
  descriptor accent.
- `logo-horizontal-navy.svg` — one-colour navy lockup on a light background.
- `logo-horizontal-reverse-cream.svg` — one-colour cream lockup on navy.
- `logo-stacked-color.svg` and `logo-stacked-reverse-cream.svg` — vertical
  lockups for compact layouts.
- `wordmark-only-color.svg` and `wordmark-only-reverse-cream.svg` — outlined
  type-only treatments.
- `symbol-color.svg` is foreground-only and requires a navy field. Also
  provided: `symbol-monochrome-navy.svg`,
  `symbol-monochrome-black.svg`, and `symbol-reverse-cream.svg` — foreground
  symbol treatments without a tile.
