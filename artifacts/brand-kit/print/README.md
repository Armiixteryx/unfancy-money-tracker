# Print vector proofs

These PDFs contain vector geometry, not rasterised logo art. The lettering is
outlined and no font is required. They retain the approved RGB colours; ask the
printer to convert and proof to the target CMYK/spot profile before production.
Use the SVGs in `../masters/` when the layout needs transparent artwork or
further editing.

- `primary-icon.pdf`
- `logo-horizontal-color.pdf` and `logo-horizontal-reverse.pdf`
- `logo-stacked-color.pdf`
- `wordmark-only-color.pdf`
- `symbol-monochrome-black.pdf`
